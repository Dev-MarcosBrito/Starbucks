<h1>☕ Starbucks — Landing Page Mobile First</h1>

<p>
  Uma <strong>landing page interativa</strong> inspirada na marca Starbucks, desenvolvida com foco em
  <em>responsividade</em>, <em>design moderno</em> e <em>experiência do usuário</em>.  
  O projeto foi baseado no tutorial da criadora <strong>Larissa Kich</strong>, com aprimoramentos de código, organização e estilização para entregar uma experiência fluida em dispositivos móveis e desktop.
</p>

<h2>✨ Principais Recursos</h2>
<ul>
  <li>Layout <strong>mobile first</strong> com adaptação para tablet e desktop.</li>
  <li><strong>Menu responsivo</strong> com animação e ícone interativo (hambúrguer / fechar).</li>
  <li><strong>Header fixo</strong> com efeito de sombra dinâmico ao rolar a página.</li>
  <li><strong>Seções modulares</strong> — Home, Em Alta, Sobre Nós e Novidades.</li>
  <li><strong>Cards de produtos</strong> com avaliações, efeitos visuais e imagens otimizadas.</li>
  <li><strong>Botões estilizados</strong> (default / outlined) com transições suaves.</li>
  <li><strong>Tipografia moderna</strong> utilizando a fonte Poppins via Google Fonts.</li>
  <li>Paleta de cores com <code>CSS Variables</code> para fácil manutenção e consistência.</li>
  <li><strong>Design temático</strong> com elementos de background e sombras sutis.</li>
</ul>

<h2>🧭 Boas Práticas Adotadas</h2>
<ul>
  <li><strong>Semântica:</strong> uso correto de <code>&lt;header&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;section&gt;</code> e <code>&lt;footer&gt;</code>.</li>
  <li><strong>Responsividade:</strong> layout projetado com a abordagem <em>mobile first</em>, utilizando breakpoints em 768px e 1200px.</li>
  <li><strong>UX/UI:</strong> navegação clara, hierarquia visual equilibrada e contrastes adequados.</li>
  <li><strong>Organização:</strong> estilos modulares em arquivos separados (<code>navbar.css</code>, <code>about.css</code>, etc.) dentro de <code>src/css</code>.</li>
  <li><strong>Performance:</strong> uso de imagens otimizadas e background adaptável para diferentes telas.</li>
</ul>

<h2>🧩 Tecnologias Utilizadas</h2>
<ul>
  <li><strong>HTML5</strong> — marcação semântica e estrutura hierárquica clara.</li>
  <li><strong>CSS3</strong> — responsividade, variáveis globais, sombras, e layout com flexbox.</li>
  <li><strong>JavaScript (Vanilla)</strong> — controle do menu mobile e efeitos de scroll.</li>
  <li><strong>Font Awesome</strong> — ícones dinâmicos (menu e estrelas de avaliação).</li>
  <li><strong>Google Fonts</strong> — tipografia Poppins.</li>
</ul>

<h2>🆕 Implementações Adicionais</h2>
<ul>
  <li><strong>Header dinâmico:</strong> adiciona sombra automaticamente ao rolar a página.</li>
  <li><strong>Menu mobile interativo:</strong> alterna ícones de abrir/fechar com transição suave.</li>
  <li><strong>Layout flexível:</strong> seções se adaptam de colunas para linhas em telas maiores.</li>
  <li><strong>Sombras e transparências:</strong> para dar sensação de profundidade e destaque.</li>
  <li><strong>Design visual refinado:</strong> uso de <code>clamp()</code> para tamanhos fluidos e legibilidade em múltiplos dispositivos.</li>
</ul>
